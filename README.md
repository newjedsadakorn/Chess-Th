# หมากรุก — เล่นคนเดียวกับคอมพิวเตอร์ ♟️

เกมหมากรุกสากลแบบไฟล์เดียว (HTML + CSS + JavaScript ล้วน) เล่นได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร

**เวอร์ชันปัจจุบัน: 1.6.1** (ดูรายละเอียดใน [CHANGELOG.md](CHANGELOG.md))

## ความสามารถ
- เล่นกับบอท 3 ระดับ (ง่าย 600, ปานกลาง 1000, ยาก 1400) พร้อมจับเวลา 5/10/15 นาที
- กติกาครบ: เข้าป้อม, กินผ่าน (en passant), เลื่อนขั้นเบี้ย, รุกจน, อับ, ซ้ำ 3 ครั้ง, กฎ 50 ตา
- สรุปเกมหลังจบ: กราฟความได้เปรียบ, ความแม่นยำ, ประเภทการเดิน 10 แบบ, เรตติ้งประเมิน, สถิติตามช่วงเกม
- ประวัติการเล่นย้อนหลัง 60 เกม
- บทเรียนเทคนิครายวัน 14 บท, ล็อกอินรายวันรับเหรียญ
- ธีมกระดาน 35 แบบ พร้อมหมาก 6 รูปทรง

## ติดตั้งลงมือถือ
ต้องเปิดผ่านลิงก์ GitHub Pages (https) เท่านั้น เปิดไฟล์จากเครื่องโดยตรงจะติดตั้งไม่ได้
- **Android (Chrome):** กดปุ่ม "ติดตั้งลงมือถือ" ในเมนูเกม หรือเมนู ⋮ แล้วเลือก "ติดตั้งแอป"
- **iPhone / iPad (Safari):** แตะปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
- ถ้าเปิดลิงก์จาก LINE หรือ Facebook ให้เลือก "เปิดในเบราว์เซอร์" ก่อน

## วิธีเล่นบนเครื่อง
ดาวน์โหลดแล้วดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

## เผยแพร่ด้วย GitHub Pages
1. อัปโหลด repo นี้ขึ้น GitHub
2. ไปที่ **Settings → Pages**
3. ที่ **Source** เลือก `Deploy from a branch` แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด Save
4. รอประมาณ 1 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (engine, UI, ข้อมูลธีมและบทเรียน) |
| `manifest.webmanifest` | ข้อมูลแอปสำหรับติดตั้งลงมือถือ (ชื่อ ไอคอน สี) |
| `sw.js` | service worker ให้ติดตั้งได้และเล่นออฟไลน์ |
| `icon-*.png`, `apple-touch-icon.png` | ไอคอนแอป |
| `VERSION` | หมายเลขเวอร์ชันปัจจุบัน |
| `CHANGELOG.md` | บันทึกการเปลี่ยนแปลงแต่ละเวอร์ชัน |

## การออกเวอร์ชันใหม่
1. แก้ `index.html` แล้วเปลี่ยนเลขเวอร์ชันใน 4 จุด: แท็ก `<meta name="version">`, ค่าคงที่ `APP_VERSION`, ค่า `VERSION` ใน `sw.js` (สำคัญ ไม่อย่างนั้นมือถือที่ติดตั้งแล้วจะไม่อัปเดต) และไฟล์ `VERSION`
2. เพิ่มหัวข้อใหม่ใน `CHANGELOG.md`
3. commit แล้วติด tag เช่น
   ```bash
   git commit -am "v1.7.0: รายละเอียด"
   git tag -a v1.7.0 -m "เวอร์ชัน 1.7.0"
   git push && git push --tags
   ```

## ข้อมูลผู้เล่น
ข้อมูล (เหรียญ, ธีม, เรตติ้ง, ประวัติ) เก็บใน `localStorage` ของเบราว์เซอร์ภายใต้คีย์ `chess-app-v2` ถ้าเปลี่ยนโดเมนหรือเบราว์เซอร์ ข้อมูลจะไม่ตามไปด้วย
